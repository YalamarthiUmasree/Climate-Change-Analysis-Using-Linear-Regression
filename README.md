# Climate Change Analysis Using Linear Regression

## Overview
This project analyzes climate temperature trends using Linear Regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Linear Regression Model Training
4. Temperature Trend Prediction
5. Data Visualization

## Results
The model demonstrates an increasing temperature trend over time, highlighting the impact of climate change.

## Files
- Climate_Analysis.ipynb : Jupyter Notebook containing the analysis
- temperature_trend.png : Visualization of temperature trends
